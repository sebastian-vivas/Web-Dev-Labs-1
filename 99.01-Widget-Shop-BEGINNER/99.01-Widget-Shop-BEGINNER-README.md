### How the shop is organized

Every feature in the shop follows the same pattern: **something happens (an event), the code changes the data, and then the page is redrawn from the data.**

| Layer | What it is | Where you meet it |
| --- | --- | --- |
| **Data** | Variables and objects that hold what is true: `products`, `cart`, `coupons` | Part 1 |
| **Helper functions** | Functions that work something out and `return` it: `getPrice()`, `calcTotals()` | Parts 1, 3, 4 |
| **Display functions** | Functions that put the data on the page: `showProduct()`, `updateCart()` | Parts 1, 3, 4 |
| **Events** | `addEventListener` lines that run a function when the user clicks, types, or presses a key | Parts 2 to 6 |

### Words you will see

| Word | Meaning here |

| **constant** | A variable made with `const`. You can't give it a new value. |

17. Create a function named `getGreeting` that takes an `hour` (0 to 23) and returns the greeting text.

**What to do:**

- One parameter: `hour`.
- If `hour` is less than 12, return `"Good Morning"`.
- Else if `hour` is less than 18, return `"Good Afternoon"`.
- Otherwise, return `"Good Evening"`.
- Use `if` / `else if` / `else`, and check the **smallest** hours first.

```js
function getGreeting(hour) {
  if (hour < 12) {
    return "Good Morning";
  } else if (hour < 18) {
    return "Good Afternoon";
  } else {
    return "Good Evening";
  }
}
```

**Check it in the console** (type these in the console and press Enter):

```js
console.log(getGreeting(9)); // Good Morning
console.log(getGreeting(15)); // Good Afternoon
console.log(getGreeting(20)); // Good Evening
```

**What you should see:** Nothing changes on the page yet. In the console you get the three greetings.

**Why it works:** The chain stops at the first condition that is true, just like the grade calculator. 3 PM (hour 15) is not less than 12, but it is less than 18, so it gets "Good Afternoon." If you checked "less than 18" first, a 9 AM visitor would get "Good Afternoon."

18. Create a function named `getDateString` that takes a `date` and returns text like `"Friday, October 16, 2026"`.

**What to do:**

```js
function getDateString(date) {
  return `${DAYS[date.getDay()]}, ${MONTHS[date.getMonth()]} ${date.getDate()}, ${date.getFullYear()}`;

```

**Check it in the console** (type these in the console and press Enter):

**What you should see:** Nothing changes on the page yet. In the console you get `Friday, October 16, 2026`.

**Why it works:** Each `${ ... }` inside backticks is replaced by its value. `getDate()` is the day of the month (1 to 31), and, unlike `getDay()` and `getMonth()`, it starts at 1.

22. Create a function named `toggleDarkMode` that switches dark mode on or off.

**What to do:**

- No parameters.
- If `darkMode` is `true`: remove the class `"dark-mode"` from the page's body with `document.body.classList.remove("dark-mode")`, then set `darkMode` to `false`.
- Otherwise: add the class with `classList.add("dark-mode")`, then set `darkMode` to `true`.

```js
function toggleDarkMode() {
  if (darkMode) {
    document.body.classList.remove("dark-mode");
    darkMode = false;
  } else {
    document.body.classList.add("dark-mode");
    darkMode = true;
  }
}
```

**Check it in the console** (type these in the console and press Enter):

```js

toggleDarkMode();
console.log(darkMode); // false
```
